# Glossary: Student Home Screen

## Main Areas

- **Header**: school context, screen title, and theme toggle.
- **Balance Alert**: cafeteria balance and quick refill request actions.
- **Next Lesson**: current and upcoming class snapshot.
- **Menu of the Day**: highlighted school meal content.
- **Buffet Carousel**: horizontally scrollable list of purchasable items.
- **Attendance Card**: time-at-school and entry snapshots.
- **Mood Picker**: quick day sentiment input.

## UI Behavior

- **Theme Toggle**: switches light and dark modes by changing `data-theme`.
- **Mood Selection**: only one mood can be active at a time.
- **Toast Messages**: short feedback for button actions.
